Glosario Técnico de Redes

IP
Internet Protocol
Protocolo que identifica y localiza dispositivos en una red.
DHCP
Dynamic Host Configuration Protocol
Asigna automáticamente direcciones IP a los dispositivos de una red.
DNS
Domain Name System
Traduce nombres de dominio a direcciones IP.
LAN
Local Area Network
Red que conecta equipos dentro de un área local (oficina, edificio, hogar).
VPN
Virtual Private Network
Permite crear una conexión segura entre redes a través de Internet.
