Instalación de Linux

Pasos principales

  1. Descargar la imagen ISO
  2. Crear un USB booteable
  3. Configurar la BIOS
    1. Entrar en BIOS con F2 o Supr
    2. Configurar el arranque desde USB
    3. Guardar cambios y reiniciar
  4. Instalar el sistema
  5. Configurar el usuario
  6. Actualizar el sistema

Desinstalación (orden inverso)

  1. Eliminar el usuario
  2. Desinstalar el sistema operativo
  3. Restaurar configuración de BIOS
  4. Formatear USB
  5. Eliminar imagen ISO
